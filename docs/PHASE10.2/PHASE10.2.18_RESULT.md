# Phase 10.2.18 结果：纯顺位多因素诊断

日期：2026-11-14。没有进行模型训练或强度评估。本阶段对 λ=.95 seed43、λ=1.0 seed44 的既有 checkpoint 做独立 critic/GAE 诊断与相同状态行为分析。Phase10.2.17 λ=.99 seed45 仅完成 5/10 epoch，未进入诊断比较。

## 证据与核验

- 两个 checkpoint 各跑 384 场新诊断局，sampling/greedy 各 192 场，每模式 64 场校准、128 场 holdout。seed 为 1,200,000–1,200,191；对局、座位、轨迹 SHA、终局、奖励账本和动作合法性由 `scripts/verify_phase10_2_18_diagnostics.py` 逐项复核，`independent_verification.json` 两项均 PASS。
- Sampling value 的纯顺位回报 skill：λ=.95 为 +0.2940，95% CI[+0.1876,+0.3821]；λ=1.0 为 +0.2999，CI[+0.1875,+0.3909]。Greedy 分别为 +0.3048，CI[+0.2262,+0.3771]；+0.2217，CI[+0.1014,+0.3319]。两模型均优于常数基线；区间重叠，不能宣称一者 critic 更优或 critic 已完全解决动作优势误差。
- 同一策略轨迹内重算 GAE：λ=.95 checkpoint 的符号一致率从 λ=.95 的 67.07% 提高至 λ=.99 的 83.78%、λ=1 的 100%；相应局内方差为 0.03738、0.13591、0.31614。λ=1 的 100% 是 MC−V 恒等式，不是质量门。λ=1 checkpoint 同样呈现 63.89%、82.54%、100%，方差 0.04220、0.14336、0.30111。该分析说明 .99 是信用传播/方差折衷候选；不证明策略强度会上升。
- 纯顺位终局回报在一局内对所有决策步相同，故局内 value correlation/EV 没有定义（返回 null）；这不是诊断失败。应使用对局级回报与常数基线比较。
- 同 BC-v4 训练/开发状态上，两个 PPO checkpoint 的动作一致率约 93.8%–94.0%。不同主要是弃牌牌张；涉及吃碰的分歧分别只有 4–12 次/约 5,600–5,800 个选择状态。立直概率差约 +1.53 至 +2.18 个百分点。该概率差不是立直动作翻转率；这些弃牌分歧没有反事实收益标签，不能判断优劣。
- 训练日志中 BC KL 的末轮均值约 .00375（λ=.95）和 .00461（λ=1.0），按 beta=.1 换算的 KL loss 项约 .000375/.000461；target-KL=.01 分别只在 10 轮中的 1/0 轮触发 early stop。两轮 approx-KL、clip fraction也低于门限很多。不同 seed 混杂，故这些值不足以因果排除锚效应，但不支持先调低 BC/call anchor 或放宽 target-KL。
- 纯顺位 λ=.95 的既有独立 10k screen 均差 −0.0167、95% CI[−0.0398,+0.0058]，未过强度门；λ=1.0 新 2k screen 均差 +0.0185、CI[−0.0345,+0.0705]，有效 NO_GO。λ=.95 与 λ=1.0 的训练 seed 不同，不能把 EV/方差差异归因于 λ。

## 多因素归因结论

| 候选因素 | 当前证据 | 处理 |
|---|---|---|
| 终局奖励的信用传播与方差 | λ=.95 的 GAE 符号一致率较低；λ=.99 明显增加一致率，方差仍低于 λ=1 的完整 MC | 保留为唯一直接支持的训练假设，重新完整筛 λ=.99 |
| Critic 完全失效 | 新 holdout sampling/greedy 都显著优于常数基线 | 暂不改 critic trunk/初始化；不能据此保证动作优势无误 |
| BC/call anchor 过强 | 动作总体接近 BC、吃碰分歧少，但没有反事实证据；KL loss占比不能单独说明约束梯度的作用 | 不调 beta，不宣称排除；留作后续仅在新证据出现时复查 |
| target-KL/clip 阻断更新 | early-stop 极少，approx-KL 与 clip fraction 较小 | 不放宽 KL 或 clip |
| reward、数据、非法动作或评估账本错误 | 本次诊断的纯顺位回报、seed、轨迹与合法性检查通过；既有强度批亦有独立原始局复算 | 当前没有支持此类 bug 的证据 |
| seed/采样不确定性 | 两次 PPO 训练 seed 不同；λ=1 的 2k CI 宽 | 新候选用新训练/评估 seed，并严格按 screen/正式评估门判断；不把跨实验差异解释为因果 |

## 决策

全面审查没有找到第二个足以与 λ 组合修改的控制因素。故不拼凑一个多参数配方；基于 GAE/MC−V 的新轨迹诊断，对 λ=.99 做一次完整、全新 seed 的预注册候选验证。它是综合审查后的单一、可证伪子假设，不是继续逐项扫 λ。方案见 [`PHASE10.2.19.md`](PHASE10.2.19.md)。
