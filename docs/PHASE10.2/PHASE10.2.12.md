# Phase10.2.12：剩余动作分歧与完整回报诊断

2026-11-14。10.2.11正式10k对有效NO_GO：顺位差−0.0091、95%CI[−0.032,+0.014]。吃碰约束已把每局副露差压到+0.0584，但未证明达到强度目标。此时没有理由再提高吃碰约束或复用10.2.11评估seed调参。

## 冻结诊断范围

1. 仅在既有10.2.9 BC-v4 sampling轨迹的训练前32局、开发前32局比较BC-v4与10.2.11 PPO相同状态下的贪心动作。分开报告吃碰翻转、非吃碰动作类型翻转、同为打牌但牌张不同、立直机会的概率变化；用局为单位统计，不把逐步状态当独立样本。此数据只描述决策差异，不含反事实动作结果。
2. 为10.2.11冻结checkpoint采集**新seed**的完整learner轨迹，与3×greedy BC-v4对局；sampling与greedy各使用同一批seed990000–990191，64局校准、128局保留，按seat=index%4，8 CPU workers。原始奖励、特征、合法mask、动作、value、MC回报、阶段与最终顺位落盘；必须通过账本、终局、checkpoint SHA和文件SHA检查。预计约2–5分钟（10.2.6同类768局285.856秒，本轮384局）。无actor训练，无强度对局门。
3. 主检查为sampling保留局的**可选状态**：PPO value相对仅用校准局拟合的常数基线之每游戏等权MSE skill与游戏级bootstrap区间。greedy另列。辅助检查GAE λ0.95/0.97/1.0对完整MC−V的符号一致率与方差、分动作机会及局阶段；λ1与MC−V的恒等式不构成选择证据。总回报分解为点数与顺位bonus，量化两者对当前目标的影响。不得用保留局调参。
4. 若同seed结果确认sampling与greedy存在显著模式差异，只额外检查一个预先指定的中间温度T=0.5。保持同checkpoint、同seed/split/对手，sampling时按`softmax(logits/T)`采动作并保存对应行为logprob；不改环境、奖励或actor。须核对动作logprob与采样分布严格一致。中间温度只用于判断是否值得设计正式版本化训练，不使用旧强度seed。仅当保留128局同seed配对下，T0.5相对T1完整回报差的游戏级95%CI下界>0、顺位差CI上界<0，且两项点估计至少缩小T1到greedy差距的一半，才进入温度版PPO工程设计；任一失败则停止该假设，不启动100k训练或强度评估。此门只说明冻结策略的采样分布更接近部署，并不证明温度版PPO训练会提升强度。

## 后续决策

诊断若暴露可复现的实现错误，先修正确性并做定向测试。若只是预测质量不稳、GAE噪声或动作分歧，不能从相关性推出具体动作的因果价值。只有提出一个可证伪的单变量机制、冻结训练和小批验证门、并在新seed小批结果通过后，才允许另一次10k/臂正式强度评估。若证据不足或小批未通过，记录NO_GO并停在诊断，不为达到阶段目标而反复调参或跑长评估。

## T=0.5前置门通过后的冻结PPO候选

同seed完整轨迹确认T0.5配对回报与顺位均显著优于T1，分别走完到greedy差距的76.9%与82.5%；详见RESULT。这只支持缩小训练/部署行为差距的工程实验。配置`configs/train_ppo_v4_tempered.yaml`，SHA-256=`c2096e93dfbb8c0367d857b6328cdf02b721015eb4545a16fa3aa24171111d2c`。与10.2.11唯一训练变量是`model.policy_temperature: 0.5`；BC-v4权重初始化、公开value、吃碰anchor1.0、全动作anchor0.1、seed42、10×10000 learner transitions、对手3×greedy BC-v4和其余优化设置均保持。模型`forward`输出已温度缩放的合法logits，所以采样、保存old_logprob、PPO ratio、entropy和冻结BC anchor统一在T0.5分布上；greedy argmax与原BC初始化一致，checkpoint按版本恢复温度。T1默认旧路径不变。不可只改rollout采样而让PPO loss仍用T1概率。

门控顺序：

1. 定向测试、2×2048 CUDA pilot：温度概率/greedy argmax、BC anchor初始化一致、采样old_logprob与更新概率一致，非法0、loss有限、value/actor更新且checkpoint严格加载。失败则修实现，不进入100k。
2. seed42正式100k训练：精确10轮/100k、非法0、loss有限、best/latest epoch10同权重、config SHA一致。预计12–20分钟，参考10.2.10/11实测733/约738秒；不设上限。
3. 固定BC状态的行为门：开发32局新候选与同温度BC的吃碰概率差≤+0.015，贪心动作一致率≥0.90，训练32局同向；只检查未发生明显行为崩溃，不作强度证据。
4. 全新seed800000–801999的2000对小批配对：候选/BC-v4镜像各2000局、16 workers、PCG64 bootstrap seed10344/10000次、normal99-v2。要求完整有效/非法0、镜像均位距1.5≤0.05（比normal99-v2更严）、候选−镜像配对均差≤−0.020且95%CI上界<0。任一失败停止，不补seed、不调温度或门槛。10.2.11的小批镜像1.581接近旧容差边缘、CI跨0却通过资源门，正式独立10k未过GO；本轮提高筛选证据门，接受由此可能漏掉微弱真实改善的代价。即使本轮小批通过，也不能代替正式独立强度门。基于10.2.11的1000对635秒及同类10k约5593秒，预计约18–23分钟；超过20分钟按无上限、无实时监控运行。
5. 仅小批通过时启动全新seed820000–829999的10k/臂正式评估，16 workers、bootstrap seed10345/10000次、normal99-v2；GO仍为均差≤−0.020且CI上界<0、完整合法镜像有效。预计90–110分钟，不设上限、不实时监控。失败则BC-v4继续为强度基线。

单次候选固定epoch10，不按短跑或小批结果挑epoch。上述2000对门在评估启动前冻结；前置T0.5轨迹不是与BC-v4的正式强度结果。
