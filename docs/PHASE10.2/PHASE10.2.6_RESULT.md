# Phase10.2.6 正式诊断结果

2026-11-14：已按整合方案完成全部768游戏，主判定INCONCLUSIVE，不是强度NO_GO，也不能改写成critic已被证实无效。独立回报与统计核验通过。本阶段没有训练actor、没有新增强度评估、没有改动模型权重。

## 采集与独立核验

- 冻结10.2.5 epoch11 PPO actor/critic，对手为3×greedy BC-v4。sampling/T1主分布、greedy/T1辅助分布各384游戏；每模式128校准+256保留，按seed整局划分，各split四席平衡。
- 正式耗时285.856秒（4分46秒），450842 learner transitions。8 CPU workers、每worker torch线程1；原估6–12分钟偏保守，以本次同类实测校准后续。
- 模型/配置/源文件与每game数据SHA一致；完整终局、非法0、mask/动作、done、数据长度和种子划分检查通过。
- 独立从逐步reward重建MC，并从feature-v3当前点数及终局点数/bonus重建逐状态目标；最大误差3.05e-6（点数单位为千点的float32编码误差），未发现样本中的奖励时间错位或重复计奖。
- 独立复算sampling/greedy的校准常数、游戏等权MSE skill和PCG64 seed10326/10000次bootstrap，与正式输出一致。
- 证据：`experiments/ppo_v4_critic_diagnostic/phase10_2_6_v1/{state.json,result.json,manifest.json,independent_verification.json}`；脚本`scripts/verify_phase10_2_6.py`。

## 主指标与辅助分布

skill=1−MSE(critic)/MSE(校准集常数)。正值为误差降低；主口径为有选择状态、先每游戏平均再游戏等权。

| 指标 | sampling（主） | greedy（辅助） |
|---|---:|---:|
| 保留游戏数 | 256 | 256 |
| critic MSE | 201.6676 | 250.0178 |
| 常数基线MSE | 194.8664 | 248.2071 |
| 原始critic skill | −3.490% | −0.730% |
| 95%区间 | [−8.009%, +0.664%] | [−5.756%, +4.484%] |
| 原始critic诊断门 | INCONCLUSIVE | INCONCLUSIVE |
| 仿射校准skill（辅助） | +0.104% | −0.0092% |
| 仿射校准95%区间 | [−0.111%, +0.315%] | [−0.0164%, −0.0022%] |

原始critic尚未显示超过简单常数预测的独立收益；sampling区间允许小幅正收益，不能断言完全无用。greedy仿射辅助项虽为FAIL，但效应极小，不能替代sampling主门，也不能当作新增强度结论。全状态口径主skill亦为INCONCLUSIVE。

sampling逐游戏EV均值−0.0632、95%区间[−0.0894,−0.0403]，逐游戏相关系数均值0.0495、区间[0.0213,0.0775]。这是局内中心化的辅助口径，不能替代跨游戏绝对误差主门。弱正相关与MSE无改善并不矛盾。

仿射校准在sampling上只得到接近零的误差改善，未显示仅改输出尺度/偏置就能解决问题；不能把它当充分修复。两种策略模式的校准集常数分别−5.7996/+1.0011，提示分布不可混合，但该均值差也含抽样波动。

## 本轮分流与下一步

执行预注册INCONCLUSIVE分支：保留证据不足，不自动补本轮样本到显著，不直接扩大actor预算、不放松anchor、不切lambda1。本轮未证明critic是唯一根因，但进一步投资critic可学习性诊断比重复强度评估更有依据。

下一份组合方案优先检验：固定与下一次初始化一致的BC-v4 sampling actor，对齐3×greedy BC-v4对手；收集新的完整回报训练/开发/最终验证游戏，检验现有独立critic是否能通过完整回报监督学出样本外收益。先比较训练与开发误差、常数/简单基线，再决定预热数据覆盖、目标或优化方案；不能仅在旧PPO数据上拟合一个critic就直接接到BC actor。

本轮256保留seed/模式已用于诊断，封存，不继续据其结果调参。拟合充分但开发不改善时检查覆盖/可预测噪声/表示；训练也不能拟合时先查目标/优化。只有有界学习诊断支持改进后，才冻结下一套actor训练预算与一次10k强度门。保留用户要求的集中诊断/组合调整流程，不恢复每单项一轮长评估。
