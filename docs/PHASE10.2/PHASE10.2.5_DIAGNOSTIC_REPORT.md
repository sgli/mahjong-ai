# PPO 强度门失败诊断报告（结合 Phase 10.2.5）

**日期：** 2026-11-14（Asia/Shanghai）  
**用途：** 在《共识版_调整稿_PPO强度门失败归因_2026-11-14.md》基础上，纳入 Phase 10.2.5 正式结果，对现有证据重新归纳，提出可执行的下一步诊断顺序。  
**范围：** 2026-11-14按用户要求整合修订。10.2.5结果及其预注册门不变；后续实施转入`PHASE10.2.6.md`。用户本轮已要求按10.2.6推进，执行范围先为冻结策略的有界诊断，不自动启动新actor训练或强度评估。

## 1. 结论摘要

1. **原共识的核心结论仍成立。** 截至 Phase 10.2.5，PPO 尚未通过预注册强度门；10.2.1、10.2.2、10.2.4 是有效 NO-GO，10.2.3 因镜像 sanity 失败而无效。10.2.5 本身有效，但仍是 NO-GO。
2. **10.2.5 改善了策略稳定性和相对 BC-v4 的接近程度，却没有证明 PPO 获得了可确认的强度增益。** 配对差为 −0.0119，95% CI 为 [−0.0358, +0.0116025]；预注册要求均值不高于 −0.020 且区间上界小于 0，两项均未满足。不能晋升，也不能据此声称 PPO 与 BC-v4 等效。
3. **目前最合理的优先诊断方向是：固定当前候选策略，检验 critic 对完整游戏回报/顺位的样本外预测能力，并检查 GAE 优势信号与实际完整回报的对应关系。** 这是依据当前低 EV、有限完整轨迹和长程信用分配特征作出的工程优先级判断，不是已经证实的根因。
4. **不要把“再增加 PPO 步数”当作下一步默认方案。** 10.2.5 的 100,000 actor transitions 只有 163 场完整 actor 游戏和 30,617 次可选动作决策，经验覆盖不大；但当前没有正式功效分析证明预算不足是主因。若目标估计或优势信号本身不可靠，直接扩预算可能只会更稳定地优化错误方向。

## 2. 10.2.5 的强度结果应如何解释

10.2.5 的强度评估完整有效：候选与镜像各 10,000 局，种子 700000–709999 完整、每席 2,500 局、非法动作均为 0，镜像均位 1.5106 通过 normal99-v2 sanity。独立复算确认配对差和置信区间。因此 NO-GO 不是由已知评估完整性问题造成的。

| 指标 | Phase 10.2.5 结果 | 正确解读 |
|---|---:|---|
| PPO 候选平均顺位 | 1.4987 | 点估计略优于本轮镜像 |
| BC-v4 镜像平均顺位 | 1.5106 | 镜像 sanity 合格，不代表其期望值必须恰为 1.5 |
| 配对顺位差 PPO−镜像 | −0.0119 | 方向有利，但未达到 −0.020 的效应门 |
| 配对差 95% CI | [−0.0358, +0.0116025] | 区间包含零，数据不能确认提升方向 |

这组结果不是“证明 PPO 没有任何增益”：区间仍包含一定程度的正向候选效果；但也绝不是通过或等效性证据。应保留预注册 NO-GO，不补样本、不改阈值、不晋升。

## 3. 多轮结果提供了什么证据

| 阶段 | 配对顺位差 | 95% CI | 有效性 | 说明 |
|---|---:|---|---|---|
| 10.2.1 | +0.54450 | [+0.52560, +0.56410] | 有效 NO-GO | 大幅退步；训练含混合对手、无稳定化控制 |
| 10.2.2 | +0.08440 | [+0.05680, +0.11220] | 有效 NO-GO | 只分离 MLP critic trunk；embedding/GRU 仍共享 |
| 10.2.3 | +0.10140 | [+0.07450, +0.12820] | **无效** | 镜像均位 1.4730 超出预注册 sanity 窗口；不计入有效失败序列 |
| 10.2.4 | +0.05990 | [+0.03280, +0.08670] | 有效 NO-GO | 完整 critic 编码器隔离；另含 Rule 菜单正确性修复等变化 |
| 10.2.5 | −0.01190 | [−0.03580, +0.0116025] | 有效 NO-GO | 组合稳定化后点估计改善、区间仍跨零 |

这些结果支持两个有限结论：

- 初期 PPO 更新确实伴随明显策略漂移和较差对局签名；10.2.5 的组合控制大幅压低了漂移，并使强度点估计相对前期改善。
- 不能把跨阶段数值变化当作单因素因果曲线。10.2.5 同时改了学习率、anchor、gradient clipping、KL 停止、entropy、warmup、decision-only 口径和训练对手分布；各阶段使用不同评估种子，10.2.4 还涉及实现修正。10.2.4 的 +0.0599 到 10.2.5 的 −0.0119 是支持后续研究的信号，不是对任一单项改动的因果估计。

## 4. 10.2.5 暴露出的信号

### 4.1 稳定性控制有效地限制了策略漂移，但不能证明“更新太大”是唯一根因

在固定的 decision-v3 validation 前 100,000 行上，10.2.4 epoch10 与 BC 的动作一致率为 85.544%，KL(BC‖PPO) 为 0.077772；10.2.5 epoch11 分别为 93.145% 和 0.017332。Gold top-1 从 67.270% 到 69.892%，BC-v4 为 70.341%。这证明本组合的候选更接近 BC-v4，且离线指标也更接近 BC；它不证明验证集牌谱动作等同于实际牌力，也不证明漂移减少带来了强度增益。

10.2.5 仍有 6.855% 的 validation 状态 greedy action 与 BC 不同，故“候选只是 BC 原样复制”也不准确。候选策略在本轮对局中的副露、立直和放铳次数仍与镜像不同。

### 4.2 当前 critic 指标是值得追查的警报，不是定案证据

10.2.5 末轮 critic 对当轮 GAE targets 的更新前解释方差为 0.03616；actor 轮次记录约 −0.041 至 0.059，首轮预热期间平均 EV 约 −0.0125。它说明在这些 rollout/target 上，critic 的预测解释力很弱。

但这些 target 本身含有当前 critic 的 bootstrap，指标并非独立完整游戏回报验证；样本还只有少量训练游戏。因而不能据此直接断言“critic 是唯一瓶颈”或“预热不足”。首先要用冻结策略、独立完整游戏的剩余reward-v1回报，与简单基线对照。现有EV包含所有状态，约七成为强制动作；新诊断以有选择的状态为主，全部状态另报。critic输出不是最终顺位，不能直接把value与rank做MSE后判断其训练目标错误。

### 4.3 GAE 的终局奖励确实会向前传播，但长距离的直接残差权重很小

实现中的递推为 `delta_t = r_t + gamma * V_(t+1) - V_t`（非终止时含 bootstrap）以及 `GAE_t = delta_t + gamma * lambda * GAE_(t+1)`。完整终局的顺位奖励被放入该席最后一个 transition，沿 GAE 反向递推；`last_value` bootstrap 主要用于非终局 rollout 截断。因此不能说终局顺位奖励“只能通过 bootstrap 才起作用”。

另一方面，10.2.5 使用 `gamma=1.0, lambda=0.95`，远处 TD residual 对当前优势的直接权重仍按 `0.95^d` 下降。这个机制使“长程信用分配/critic 对未来状态的估值是否足以承接远期目标”成为合理待测问题，但单看 lambda 公式不能证明当前强度失败就是它造成的。任意把 lambda 调高也会改变偏差—方差权衡，不能未经诊断就作为修复。

### 4.4 训练样本量和可选动作覆盖有限，但不构成预算不足证明

正式训练共 110,000 learner transitions，其中首个 10,000 为 critic-only warmup，actor 预算为 100,000 transitions；实际有 163 场完整 actor 游戏、30,617 次可选动作决策。机制审计中的强制动作比例约 69.6%，因此总 transition 数会高估 actor 获得的真正策略选择信号量。

这足以支持“互动覆盖有限、值得研究”的判断，不足以支持“把预算增至 1M 就会过门”。共识稿中的局级 `sigma/sqrt(N)` SNR 是量级代理，而非 action-conditioned policy-gradient SNR 或学习功效分析。

### 4.5 过度保守和剩余行为偏差仍是次级假设

候选相对镜像的副露次数多 14.71%、放铳多 3.65%、立直多约 4.40%；平均和牌点数低约 0.16%。前几轮的副露/放铳差距更大。这说明行为签名有所收敛但没有完全消失。然而整场次数不等于机会归一化概率，也不能说明哪种动作造成顺位差。

共识稿中的机会级审计已给出 93 次碰机会、195 次吃机会、26 次立直机会等分母；所以不应再说“完全没有机会分母”。正确限制是：该审计只有 4,755 个决策状态、机会数偏少且属描述性观测；它没有同状态的反事实后果/动作价值，不能估计总体因果影响。

anchor beta=0.1、较低学习率、关闭 entropy 可能使 actor 更新偏小，也可能只是压住了不可靠的梯度。KL(BC‖PPO)=0.017332 本身不能判定 anchor 过强；actor 仍发生变化，且本轮 strength CI 仍跨零。必须先检查更新信号和 critic 泛化，再决定是否对 anchor/学习率做单因素试验。

### 4.6 对手分布不再是本轮比较中的直接错配，但泛化范围仍窄

10.2.5 训练对手固定为 greedy BC-v4，候选评估时面对的也是 3×greedy BC-v4，因此“训练与这次强度测试对手完全错配”不能解释本轮未过门。另一方面，这只检验固定 BC-v4 greedy 对手协议；未证明对其他策略池、温度或自适应对手的泛化。

## 6. 整合后的后续流程：接入 Phase10.2.6

实施协议、预算和输出以[PHASE10.2.6.md](PHASE10.2.6.md)为准。采用集中多因素诊断、合并有依据的调整、一次正式强度评估，遵循用户要求；不恢复每项单变量各跑一次长评估。

### 6.1 修正原建议中的诊断分布

10.2.5对手是greedy BC-v4，但learner训练时为sampling/T=1，强度评估时才为greedy。critic主要拟合的是采样策略回报，故主分析采用冻结候选的sampling/T=1；greedy作为独立的部署分布诊断，不混池。若sampling通过而greedy未通过，优先检查策略模式差异，不能直接宣布critic训练失败。

采集同一批新环境种子的两种模式，每种128场校准+256场保留，共768场游戏；同seed跨模式视为相关数据。四席轮换，每场只使用learner轨迹，不能将不同策略的三家对手轨迹当成该候选的同分布训练样本。既有强度JSON缺少逐决策输入/奖励，旧机制审计只保留汇总，需新增完整轨迹；不重建Parquet。

### 6.2 对齐目标与基线，避免伪泛化

主目标为当前动作开始至终局的实际reward-v1累计回报G_t，gamma=1，已归属到trajectory的终局bonus只计一次。点数贡献和顺位bonus分别保存作诊断，原value不当作纯rank预测器。

按游戏分校准/保留，所有同局状态留在同侧；基线均值和仿射校准a+bV仅在校准集拟合。主统计以有选择状态计算每游戏MSE、每游戏等权，再以游戏为单位bootstrap；不将数十万相关状态当独立样本。

主门为sampling的原始critic相对校准集常数基线的MSE skill，其95%游戏级bootstrap区间下界>0记PASS，上界<0记FAIL，跨0或退化数据记INCONCLUSIVE。它只用于下一步工程排序，不证明critic是唯一根因，也不是PPO理论上必须有高EV才能学习。仿射校准、MAE、EV、校准分箱及阶段/最终顺位分层均为辅助，不能替换主门救回结果。

### 6.3 同一批轨迹集中检查多种机制

在缓存轨迹上离线比较lambda0.95/0.97/1.0的GAE、MC−V、方差及动作分组，不为每个lambda重跑环境或强度。lambda1在完整轨迹上与MC−V相同是代数恒等式，不能因相关性最高就选它。整局回报相关性及动作分组均不是反事实动作价值，不能证明某次吃碰正确/错误。

并行检查奖励账本、时间对齐、强制动作权重、可选动作机会、critic校准、训练/部署模式差异。保留10.2.5完整隔离、decision-only和稳定化控制，先不直接扩actor预算、不删anchor、不改奖励、不增加entropy。

### 6.4 依据结果合并调整

- sampling FAIL：先定位尺度/拟合/覆盖；冻结actor做有界critic学习对照，比较校准与完整回报监督。低EV也可能来自隐藏信息/回报噪声，不能仅凭FAIL判模型容量不足。
- sampling INCONCLUSIVE：记录证据不足，不自动追加样本直到显著；结合区间宽度、分层与拟合情况决定下一份有限预算方案。
- sampling PASS而greedy弱：保留训练critic，检查sampling→greedy差异，不盲目增加预热。
- critic预测已有价值但GAE信号可疑：在同批轨迹开展小型学习诊断，再确定时间尺度与critic目标的组合调整，不以lambda1与MC的一致性作选择依据。
- 信号可信、actor学习仍弱：再将有效选择预算与约束强度纳入同一份下一轮组合计划，保留一次正式10k强度门。

若下一候选从BC-v4初始化，其critic预训练数据必须对齐冻结BC-v4采样策略；当前PPO候选的诊断轨迹不能不加说明地当成BC策略的on-policy标签。任何critic微调与超参选择须使用另外的训练/开发划分，不反复用本轮保留集调参。

10.2.6先完成诊断报告后停止自动流程，再依据实测冻结新训练预算/参数和唯一候选选择。正式强度门维持10k、−0.020及CI上界<0；GO后才独立训练seed确认。

## 7. 最终诊断判断

Phase 10.2.5 未能验证“只要压住 actor 漂移，PPO 就会自然过门”的假设：稳定性改善很明显，但还没有确认的实战优势。与此同时，结果也没有证明稳定化控制无用；它可能是必要条件，但不是已证明的充分条件。

当前最稳妥的因果表述是：**PPO 初期存在过大策略偏移的风险；组合约束明显减轻了该风险，但候选仍未达到预注册强度标准。残余瓶颈尚未识别。低 critic 样本外质量、长程优势信号、有限有效 actor 决策量和过度保守更新都是待测机制；现阶段先验证冻结 critic 对完整回报/顺位的独立预测力，再决定是否投入 actor 训练或扩预算。**
